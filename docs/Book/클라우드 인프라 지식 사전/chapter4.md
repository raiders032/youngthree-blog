## 1. chapter4: 성능 튜닝

- 이 책에서 성능이 높다는 지연 시간이 짧다를 의미
- 성능 튜닝은 지연 시간 줄이는 일 지연 시간 줄이면 결과적 처리량도 늘어남
- 높은 성능은 사용자 체감과 만족도에 중요
    - 구글 화면 표시 100ms 느려지면 검색수 0.2 감소
    - 400ms 느려지면 0.6 감소
- 속도 평가 지표
    - LCP 2.5초 이내가 주용한 기준 서버 통신 브라우지 렌더링 까지 포함(이거 고려하면 서버와 통신은 1초 이내 완료되어야한다.)

### 3.2 계획

- 목적
- 목표성능

- 실시 기간

### 3.3 실시 준비

- 부하생성 환경과 부하 대상 환경 준비
- 부하 생성 시나리오 구현
- 모니터링 설정
- 부하생성 환경
  - 처리 성능 안정
  - 부하 대상 환경과 동등 또는 이상 네트워크 성능
  - 부하 대상 환경 사이 불안정 요소 없고 이를 관측 관리 가능해야함
  - 설정이나 운영이 용이하고 재현하기 쉽다.
  원하는 부하를 툴로 간단히 사용
- 부하 대상 환경
  - 부하 테스트 실시 응답 불안장 고장 가능
  - 따라서 프로덕션 테스트 노
  - 프로덕션과 동등한 환경과 데이터 준비
  - 데이터 재현 쉽지 않음
    - 개인정보 마스킹
    - 더미 데이터
    - 예를 들어 메일 다 같은 값으로 마스킹하면 디비 인덱스 료과 없어져 처리 속도 달라짐
- 시나리오 구현
  - 복잡하지 않고 간단히 구현 핵심
  - 아파티벤치 케이식스 제이미터 가트링 로커스트 등
  - k6 추천 작성및 실행 쉽고 처리 효율 좋고 결과 보기 쉽다.
- 모니터링 설정
