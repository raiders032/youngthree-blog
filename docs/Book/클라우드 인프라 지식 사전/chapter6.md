
## 6.1 URL

- URL은 네트워크에서 리소스의 위치를 표시하는 문자열이다.
- 구조: `스킴://유저:패스워드@호스트:포트/패스?쿼리#프래그먼트`
    - 스킴 (scheme): 사용할 프로토콜 (`https`, `http`, `ftp` 등)
    - 유저 (user): 접속에 사용할 사용자명 (생략 가능)
    - 패스워드 (password): 사용자 인증용 비밀번호 (생략 가능, URL에 노출되므로 사용을 피한다)
    - 호스트 (host): 접속할 서버의 IP 주소 또는 도메인명
    - 포트 (port): 서버 안의 접속 대상 번호 (생략하면 스킴의 기본 포트)
    - 패스 (path): 서버 안의 리소스 위치 (`/blog/post/1`)
    - 쿼리 (query): `?` 뒤에 `키=값`을 `&`로 이어 붙인 추가 정보 (`?page=2&sort=asc`)
    - 프래그먼트 (fragment): `#` 뒤에 쓰는, 리소스 안의 특정 위치 (`#section1`). 브라우저에서만 쓰이고 서버로는 전송되지 않는다.
- 대표적인 기본 포트

| 포트 | 용도 |
|---|---|
| 80 | HTTP |
| 443 | HTTPS |
| 25 | SMTP |
| 3306 | MySQL |
| 5432 | PostgreSQL |
| 6379 | Redis |
| 11211 | Memcached |

## 6.2 도메인명

- URL의 호스트에는 IP 주소 또는 도메인명을 지정한다.
- 도메인명 구조
    - 닷(`.`)으로 구분된 253문자 이하의 문자열이다.
    - 닷으로 구분된 각 문자열을 **레이블**이라고 한다.
    - 각 레이블은 63문자 이하여야 한다.
    - 사용 가능한 문자는 영문자, 숫자, 하이픈(`-`)이다.
    - 각 레이블의 처음과 마지막에는 하이픈을 쓸 수 없다.
    - 대문자와 소문자를 구분하지 않는다.
